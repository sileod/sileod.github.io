I develop open tools and datasets for reasoning, evaluation and reusable NLP research.

## Reasoning Core

[Reasoning Core](https://github.com/sileod/reasoning-core) generates verifiable textual tasks for language-model pre-training, post-training, evaluation and reinforcement learning. It covers formal logic, mathematics, planning, algorithms, syntax and related symbolic domains, with task-native scorers and more than 10 billion tokens of pre-generated data.

- [Paper](https://arxiv.org/abs/2603.02208)
- [Software](https://github.com/sileod/reasoning-core)
- [Dataset collection](https://huggingface.co/collections/reasoning-core/datasets)

## gramforge

[gramforge](https://github.com/sileod/gramforge) is a Python library for synthetic data generation with declarative context-sensitive grammars. It supports parallel generation in multiple representations, depth constraints and inspectable abstract syntax trees.

- [Paper](https://aclanthology.org/2024.emnlp-main.301/)
- [Software](https://github.com/sileod/gramforge)

## tasksource

[tasksource](https://github.com/sileod/tasksource) provides hundreds of curated and standardized NLP datasets with reusable preprocessing functions. It supports large-scale evaluation, multi-task learning and instruction-data construction.

- [Paper](https://aclanthology.org/2024.lrec-main.1361/)
- [Software](https://github.com/sileod/tasksource)

## Data Provenance Initiative

The [Data Provenance Initiative](https://www.dataprovenance.org/) develops datasets, tools and analyses for understanding the origins, licensing, attribution and evolution of training data used in AI.

- [Data Provenance Explorer](https://www.dataprovenance.org/)
- [Software and data](https://github.com/sileod/Data-Provenance-Collection)
- [ICLR 2025 paper](https://openreview.net/forum?id=G5DziesYxL)
- [NeurIPS 2024 paper](https://proceedings.neurips.cc/paper_files/paper/2024/hash/c3738949a80306cc48a8ea8ba0560f9d-Abstract-Datasets_and_Benchmarks_Track.html)

## MindGames

[MindGames](https://github.com/sileod/llm-theory-of-mind) is a dynamically generated benchmark based on epistemic modal logic for evaluating theory-of-mind reasoning in language models.

- [Paper](https://arxiv.org/abs/2305.03353)
- [Software and data](https://github.com/sileod/llm-theory-of-mind)
